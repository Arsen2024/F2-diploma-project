## Матриця нефункціональних вимог (NFR)

Умови вимірювання: 5 активних істот у тестовій сцені, вибірка ≥ 10 000 кадрів, інструмент — Unreal Insights. **(П)** — початкове значення, що підлягає уточненню за результатами прототипування.

| Категорія | Метрика / порогове значення |
|---|---|
| Продуктивність | Час кадру ≤ 16,6 мс на p95 (60 кадрів/с) за ≤ 5 активних істот |
| Продуктивність | Бюджет підсистем штучного інтелекту ≤ 2 мс на кадр на p95 (П) |
| Продуктивність | Запис збереження ≤ 500 мс; жоден кадр під час запису не перевищує 33,3 мс (П) |
| Продуктивність | Відновлення стану після завантаження рівня ≤ 2 с (П) |
| Масштабованість | 0 прямих посилань між класами різних модулів; новий тип істоти — 0 змін в інших модулях |
| Надійність | Атомарний запис: аварійне завершення не пошкоджує попереднє збереження |
| Надійність | 100 % збережень версії N−1 завантажуються після міграції |
| Якість | 100 % переходів диспозиції та сценаріїв збереження і відновлення покриті автотестами |
| Безпека | Перевірка версії, контрольної суми та меж значень файлу збереження; мережа і телеметрія відсутні |
| Інфраструктура | Збірка та автотести при кожному Pull Request (GitHub Actions + Unreal Automation Tool) |
