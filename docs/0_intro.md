# ВСТУП

## Актуальність теми

Розробка ігрових систем із нелінійною структурою проходження супроводжується зростанням складності взаємодії підсистем реального часу — керування персонажем, штучного інтелекту неігрових агентів, збереження стану та обробки скриптованих подій. Масштабування кількості одночасно активних інтелектуальних агентів прямо впливає на затримку (latency) реакції системи на дії користувача, що є критичним фактором сприйняття для жанру survival horror, де стабільність частоти кадрів і своєчасність реакції середовища визначають якість взаємодії.

Окремою проблемою є відмовостійкість (fault tolerance) механізму збереження стану: за умови нелінійного проходження та подальшого розширення схеми даних системи виникає ризик втрати цілісності збережень при зміні структури стану між версіями збірки. Відсутність формалізованого підходу до архітектурної незалежності підсистем призводить до жорсткого зв'язування компонентів, що ускладнює супровід, тестування та подальше масштабування проєкту. Це обумовлює необхідність застосування слабко зв'язаної, подієво-орієнтованої архітектури та формалізованих методів проєктування, здатних забезпечити надійність, розширюваність і прогнозовану продуктивність системи.

## Об'єкт дослідження

Процеси управління станом ігрових підсистем та обробки поведінки інтелектуальних агентів у нелінійному віртуальному середовищі реального часу.

## Предмет дослідження

Архітектурні патерни (Event-Driven Architecture, Component-Based Architecture, State Pattern, Behavior Tree Pattern), методи проєктування слабко зв'язаних програмних систем та інструментальні засоби Unreal Engine 5 (AI Perception, Behavior Tree, SaveGame System, Unreal Automation Testing Framework), що застосовуються для підвищення надійності, розширюваності та продуктивності процесів управління станом та поведінкою агентів.

## Мета роботи

Проєктування та розробка архітектури ігрових систем управління процесом на основі слабко зв'язаних, подієво-орієнтованих компонентів із застосуванням патернів State та Behavior Tree для обробки поведінки інтелектуальних агентів і стану нелінійного віртуального середовища, спрямованих на підвищення надійності, розширюваності та стабільності продуктивності системи.

## Завдання проєкту

1. Проаналізувати наявні архітектурні рішення та аналоги систем управління станом у проєктах жанру survival horror для виявлення їхніх переваг і обмежень.
2. Обґрунтувати вибір технологічного стеку (Unreal Engine 5, C++, Blueprints, архітектурні патерни Event-Driven та Component-Based) відповідно до вимог надійності, розширюваності та продуктивності системи.
3. Спроєктувати архітектуру програмного рішення із застосуванням UML/C4-діаграм (компонентів, станів, послідовності взаємодії) для формалізації структури та зв'язків між підсистемами.
4. Розробити алгоритми функціонування критичних вузлів системи: станових переходів поведінкових дерев штучного інтелекту, механізму версіонування структури збережених даних, подієво-орієнтованої комунікації тригерів.
5. Спроєктувати інтерфейс користувача (UI/HUD) та схему розгортання й складання проєкту (CI/CD-пайплайн на основі GitHub Actions та Unreal Automation Tool).
6. Провести інструментальний аудит якості реалізації шляхом автоматизованого тестування (Unreal Automation Testing Framework) та профілювання продуктивності системи (Unreal Insights).
7. Здійснити науково-практичну апробацію результатів дослідження шляхом підготовки тез або статті за темою розробленої архітектури.
