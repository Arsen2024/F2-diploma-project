# РОЗДІЛ 2. ПРОЄКТУВАННЯ АРХІТЕКТУРИ СИСТЕМИ

> **Статус:** розділ не наповнено. Контент буде додано на етапах календарного плану №3–4 (Листопад 2026 – Січень 2027). Нижче наведено структуру розділу відповідно до завдання проєкту.

## 2.1 Архітектура системи на рівні C4 Model

- [ ] Context-діаграма (рівень 1): місце системи серед зовнішніх акторів (гравець, Unreal Engine Runtime).
- [ ] Container-діаграма (рівень 2): основні підсистеми (контролер гравця, AI, збереження, тригери, UI).
- [ ] Component-діаграма (рівень 3): деталізація компонентів усередині кожної підсистеми.

## 2.2 UML-діаграми

- [ ] Діаграма компонентів (взаємозв'язки підсистем через інтерфейси).
- [ ] Діаграма станів (стани поведінки AI-агентів: ворожий / нейтральний / умовно дружній).
- [ ] Діаграма послідовності (взаємодія тригер → подієва шина → AI/освітлення/звук).

## 2.3 Схема даних

- [ ] Структура даних стану гри (SaveGame).
- [ ] Схема версіонування структури збережених даних (save data versioning).

## 2.4 Алгоритми критичних вузлів

- [ ] Алгоритм станових переходів поведінкових дерев AI.
- [ ] Алгоритм версіонування/міграції структури збережень.
- [ ] Алгоритм подієво-орієнтованої комунікації тригерів із суміжними підсистемами (освітлення/VFX/звук).
